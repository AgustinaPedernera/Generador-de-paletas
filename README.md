
# Generador de Paletas

## Descripción

Generador de paletas de colores aleatorias desarrollado como Proyecto Integrador del Módulo 1.

La aplicación permite seleccionar la cantidad de colores que se desean generar y crear una paleta de forma dinámica.

## Funcionalidades

- Generación de paletas de colores aleatorias.
- Selección de 6, 8 o 9 colores.
- Visualización de cada color mediante tarjetas.
- Visualización del código HEX de cada color.
- Copiado del código HEX al portapapeles.
- Mensajes de feedback para informar las acciones realizadas.
- Diseño responsive para diferentes tamaños de pantalla.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages

## Cómo utilizar la aplicación

1. Seleccionar la cantidad de colores deseada.
2. Hacer clic en el botón **"Generar paleta"**.
3. La aplicación generará una nueva paleta de colores aleatoria.
4. Cada tarjeta mostrará el color generado y su código HEX.
5. Para copiar un código HEX, hacer clic sobre el código correspondiente.
6. La aplicación mostrará un mensaje de confirmación cuando el código haya sido copiado.
